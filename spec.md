# TEOS Payment Rail — Specification

## Definition
A payment rail is a deterministic method for transferring value
between wallets using predefined rules.

## Settlement Layer
- Blockchain: Solana
- Asset: TEOS (SPL)
- Finality: On-chain confirmation

## Transaction Model
- Sender-signed transactions
- Direct wallet-to-wallet transfer
- No intermediaries
- No escrow by default

## Fees
- Network fee only (Solana)
- No protocol fee defined in this spec

## Transparency
All transactions are publicly auditable.
